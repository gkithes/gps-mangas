# GPS Μάγκας

Πλοήγηση με ατάκες σε Ελληνικά / Ποντιακά. Web app — ανοίγει στο κινητό και μπαίνει στην αρχική οθόνη σαν κανονική εφαρμογή.

**Άνοιγμα:** https://gkithes.github.io/gps-mangas/ (iPhone: Safari → Κοινοποίηση → Προσθήκη στην αρχική οθόνη)

Η προηγούμενη έκδοση υπάρχει ολόκληρη στο branch [`backup-v1`](https://github.com/gkithes/gps-mangas/tree/backup-v1).

## Τι κάνει
- **Διαδρομές**: έως 3 εναλλακτικές στον χάρτη με χρόνο, απόσταση, «μέσω», στροφές, διόδια, αυτοκινητόδρομο.
- **Πλοήγηση με φωνή**: οδηγίες + ατάκες, ή μόνο ατάκες, ή «σοβαρό». Ειδοποιεί νωρίτερα στην εθνική.
- **Κοντά μου** (κάτω μπάρα): βενζίνη, φαγητό, καφές, σούπερ μάρκετ, φαρμακείο, πάρκινγκ, ATM, φόρτιση EV κ.ά. — αμέσως από τη μνήμη του κινητού.
- **Αναζήτηση** πάντα κοντά σου, με προτάσεις όσο γράφεις. «βενζίνη», «gas near me» κ.λπ. ανοίγουν τα κοντινά.
- **Πρόσφατα & Αγαπημένα**, με ⋯ για διαδρομή / αγαπημένο / μετονομασία / διαγραφή.
- **Ρυθμίσεις**: χλμ ή μίλια, φωνή, ταχύτητα, τόνος, ένταση, γλώσσα ατάκων, «ντινγκ», όριο ταχύτητας, **δικές σου ηχογραφήσεις**.

## Αξιοπιστία
- Βρίσκει πού είσαι πάνω στη διαδρομή ακόμα κι αν το GPS «πετάει» 50+ μέτρα ή χαθεί για λίγο.
- Φύλακας κάθε 2″: ξεκινάει ξανά το GPS, ξεκολλάει τη φωνή, ξαναδοκιμάζει νέα διαδρομή, κρατάει την οθόνη ανοιχτή.
- Όταν γυρίζεις στην εφαρμογή (κλείδωμα οθόνης, κλήση), ξαναλέει αμέσως την τρέχουσα οδηγία.
- Εφεδρικοί διακομιστές και όρια χρόνου σε κάθε αίτημα· ποτέ δεν ψάχνει «στην τύχη» αν δεν ξέρει πού είσαι.

## Πού είναι τι
| Αρχείο | Τι κάνει |
|---|---|
| `js/phrases.js` | **Οι ατάκες** — άλλαξε/πρόσθεσε ελεύθερα ανά κατηγορία |
| `js/main.js` | Εκκίνηση, συνδέει τα πάντα |
| `js/nav.js` | Πλοήγηση: επόμενη στροφή, τι λέει και πότε, προσομοίωση |
| `js/route.js` | Διαδρομές από τον διακομιστή, κείμενα οδηγιών |
| `js/gps.js` | GPS, φύλακας, άδεια τοποθεσίας |
| `js/voice.js` | Φωνή, «ντινγκ», ηχογραφήσεις, επιλογή ατάκας |
| `js/poi.js`, `js/nearby.js` | Κοντινά μέρη και η κάτω μπάρα |
| `js/search.js` | Αναζήτηση και προτάσεις |
| `js/preview.js` | Επιλογή διαδρομής |
| `js/drawer.js` | Πρόσφατα & αγαπημένα |
| `js/settings-ui.js` | Οθόνη ρυθμίσεων |
| `js/store.js`, `js/recordings.js` | Ό,τι αποθηκεύεται στο κινητό |
| `js/config.js` | Διακομιστές και όρια |

Χάρτης: OpenStreetMap · Διαδρομές: OSRM (+ FOSSGIS) · Αναζήτηση: Photon / Nominatim · Κοντινά: Overpass · Leaflet & NoSleep.js (MIT) στο `vendor/`
