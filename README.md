# GPS Μάγκας

Πλοήγηση με ατάκες σε Ελληνικά / Ποντιακά. Web app — ανοίγει στο κινητό και μπαίνει στην αρχική οθόνη σαν κανονική εφαρμογή.

**Άνοιγμα:** https://gkithes.github.io/gps-mangas/ (στο iPhone με Safari → Κοινοποίηση → Προσθήκη στην αρχική οθόνη)

## Τι κάνει
- **Διαδρομές**: ψάξε προορισμό → βλέπεις έως 3 εναλλακτικές στον χάρτη με χρόνο, απόσταση, «μέσω», στροφές, διόδια, αυτοκινητόδρομο. Πάτα μία και «Ξεκίνα».
- **Κοντά μου** (κάτω μπάρα): βενζίνη, φαγητό, καφές, σούπερ μάρκετ, φαρμακείο, πάρκινγκ, ATM, φόρτιση EV, ξενοδοχείο, νοσοκομείο κ.ά.
- **Πρόσφατα & Αγαπημένα** (κάτω, ανοιγοκλείνει): κάθε προορισμός έχει ⋯ για διαδρομή, αγαπημένο, μετονομασία, διαγραφή.

## Ρυθμίσεις (κουμπί ⚙ πάνω δεξιά)
- **Γενικά**: χιλιόμετρα ή μίλια.
- **Φωνή**: επιλογή φωνής, ταχύτητα, τόνος, ένταση, δοκιμή.
- **Ήχος**: οδηγίες + ατάκες / μόνο ατάκες / μόνο οδηγίες (σοβαρό) / σίγαση, γλώσσα ατάκων, «ντινγκ», όριο ταχύτητας.
- **Οι δικές μου ηχογραφήσεις**: ηχογράφησε ή ανέβασε αρχείο ήχου για κάθε περίπτωση (αριστερά, δεξιά, λάθος δρόμος…). Μένουν αποθηκευμένα στο κινητό.

## Γραπτές ατάκες
Στο `phrases.js`, ανά κατηγορία (`start`, `left`, `right`, `straight`, `uturn`, `roundabout`, `highway`, `recalc`, `speeding`, `idle`, `arrive`).

Χάρτης: OpenStreetMap · Διαδρομές: OSRM · Αναζήτηση: Nominatim · Κοντινά: Overpass
