# GPS Μάγκας

Πλοήγηση με ατάκες σε Ελληνικά / Ποντιακά. Web app (PWA) — ανοίγει στο κινητό και μπαίνει στην αρχική οθόνη σαν κανονική εφαρμογή.

- Χάρτης: OpenStreetMap · Διαδρομές: OSRM · Αναζήτηση: Nominatim · Φωνή: η ελληνική φωνή του κινητού
- Οι ατάκες είναι στο `phrases.js` — άλλαξε/πρόσθεσε ό,τι θες ανά κατηγορία
  (`start`, `left`, `right`, `straight`, `uturn`, `roundabout`, `highway`, `recalc`, `speeding`, `idle`, `arrive`).
- **Προσομοίωση**: διάλεξε προορισμό και πάτα «Προσομοίωση» για να δοκιμάσεις χωρίς να οδηγείς.

## Πώς ανοίγει στο κινητό
Χρειάζεται HTTPS για το GPS. Ο πιο εύκολος τρόπος: GitHub Pages
(Settings → Pages → Branch: `main`, φάκελος `/ (root)`), μετά άνοιξε
`https://gkithes.github.io/gps-mangas/` και «Προσθήκη στην αρχική οθόνη».
